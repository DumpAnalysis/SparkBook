Find a recorded run

From the companion or the working lab, display the guide and recorded results:
  python3 reader/guide.py 25
  python3 reader/records.py 25 --files

A run such as 025.01 identifies an observation in the book. The index shows
the printed page, the execution scope and what to inspect first. Some exercises
share a capture or have a recorded assessment without a separate printed command.
Use the page and run ID to read the transcript in the printed or digital book.

Optional text export from the Version 56 Word book
From your working lab, run:
  python3 reader/import_transcripts.py /path/to/Local_AI_on_RTX_Spark_Laptops_Version56.docx
  python3 reader/records.py 25 --files

The exporter reads the DOCX without running embedded commands. It verifies
all 483 published capture digests and creates runs/book-transcripts/ with one
UTF-8 file per run. The file for the example is 025.01.txt. The destination
must be new. Historical paths retain their original spelling. The published
account mask is preserved. Use reader/capture.py and a fresh run directory
to capture your own stdout, stderr and exit status.
