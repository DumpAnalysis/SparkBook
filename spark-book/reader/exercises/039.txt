Exercise 39  Capture four annotated iterations

Question
Can we see the four host annotations alongside actual device activity?

Technology background

Nsight Systems, NVTX and CUPTI timelines

Nsight Systems records a timeline across CPU threads, CUDA API calls and supported GPU activity. NVTX lets the application name a region such as “iteration 2”. CUPTI is an NVIDIA interface that tools can use to collect activity records. A host range describes what the CPU was doing while it was open.

Start with one named iteration. Look for the CPU launch call, then the corresponding GPU work with usable start and end times. A launch returning to the CPU does not mark the end of device execution. Zero device timestamps leave the duration unresolved.

Interpret the result
Count four transform kernels with positive device intervals and four NVTX iteration ranges. Inspect their boundaries separately. On the reader’s N1X, native 2026.3.2 produced host ranges without the CUPTI kernel table. Keep the simulator or host-only result separately if collection is unavailable.

If the check fails
Keep the successful numerical or host-range control. Record the driver, tool version, activity table and count of kernel intervals with end greater than start. If that count is zero, mark device duration unavailable. Use cuda/timestamp_probe/reproduce_timestamps.py for the independent CUPTI check.

Finish
Keep original Nsight Systems report.
