Exercise 129  Qualify DDP and the transition to multiple GPUs

Question
Which parts of a multi-device training procedure can one physical GPU qualify?

Technology background

Distributed training on one physical laptop

Distributed training uses several processes that coordinate their work. Each process has a rank, its identifier within a group. World size is the number of participating processes. A rendezvous brings those ranks together. Gloo and NVIDIA’s NCCL are communication backends used in different configurations.

On one laptop, two CPU processes can act as two ranks over loopback and expose coordination, delays or failures. They still share one physical machine. A one-rank NCCL check can exercise the available GPU. Two-device training requires two independently addressable CUDA devices.

Data parallelism, sharding and gradient averaging

In data parallelism each worker holds a model replica and processes part of the batch. PyTorch DistributedDataParallel (DDP) averages gradients across participating ranks through an all-reduce. When ranks process unequal numbers of examples, weight their mean gradients by sample count to recover the global example mean.

Sharding divides storage or computation across workers. Fully Sharded Data Parallel (FSDP) partitions training state. The column-sharding exercise partitions a matrix and compares the resulting calculation and gradients with an unpartitioned CPU reference.

Reading the result
Read the results in three steps. Native CPU DDP ended with rank 0 SIGSEGV on the laptop. The two logical loopback nodes worked. Single-rank NCCL worked on one physical GPU. Distinct-device DDP remained unavailable.

Run in your lab
Run the two CPU/Gloo commands separately and keep launch.json, rank logs, exits and the reference comparison for each. If the INFO trial fails, repeat it in a fresh directory with --debug-level OFF. The final command checks a separate two-device NCCL prerequisite.

: "${LAB_RUN:?Start a new lab run first}"
python distributed/lab.py ddp --workers 2 --debug-level INFO --out "$LAB_RUN/ddp-info"
python distributed/lab.py nodes --workers 2 --debug-level INFO --out "$LAB_RUN/nodes-info"
# Separate hardware prerequisite check. Two devices are required.
python distributed/lab.py gpu-ddp --workers 2 --out "$LAB_RUN/gpu-ddp"

Interpret the result
Log visible CUDA device IDs before requesting two NCCL ranks. Two CPU/Gloo workers demonstrate coordination. Two physical CUDA devices are required for the GPU DDP comparison.
