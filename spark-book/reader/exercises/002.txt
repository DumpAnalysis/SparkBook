Exercise 2  Calculate before allocating

Question
How large should the key/value cache be before the server allocates it?

Technology background

Model weights, tokens and the context window

A language model stores learned numbers called weights. A tokenizer splits text into pieces and assigns each piece an integer. A piece might be part of a word. During inference the model reads the prompt and predicts successive tokens using the existing weights. Training changes those weights.

The context window bounds how many tokens the model can use in a request. During generation a transformer saves attention keys and values for earlier positions in a KV cache. Increasing the context or serving additional sequences can require more memory even when the weight file stays exactly the same size.

Bytes, memory budgets and unified memory

One GiB is 1,073,741,824 bytes. On this 64 GB unified-memory laptop, Windows, the WSL2 guest and a CUDA process describe memory from different positions. The free command reports guest RAM. nvidia-smi reports the management interface’s GPU memory view. PyTorch can query the CUDA runtime for free and total bytes visible to its process.

Keep the name, unit, time and calling process beside each value. The recorded 31,232 MiB management total and 45.97 GiB CUDA total overlap. Adding them would count some of the same capacity twice. Exercise 251 tests what an allocation can actually write and verify.
