Exercise 64  Reproduce a missing dependency and repair it

Question
What ordering edge makes a consumer's read see the producer's new value?

Technology background

CUDA events and double buffering

Double buffering gives the producer a second slot while the consumer works on the first. Record a completion event after each slot’s last use. Wait for that event before reusing the slot. An overlap claim requires overlapping device intervals.

Across streams, record an event after the producer writes and have the consumer wait on it before reading. Exercise 64 tests this dependency by comparing a stale read with the value after the wait.

Nsight Systems, NVTX and CUPTI timelines

Nsight Systems records a timeline across CPU threads, CUDA API calls and supported GPU activity. NVTX lets the application name a region such as “iteration 2”. CUPTI is an NVIDIA interface that tools can use to collect activity records. A host range describes what the CPU was doing while it was open.

Start with one named iteration. Look for the CPU launch call, then the corresponding GPU work with usable start and end times. A launch returning to the CPU does not mark the end of device execution. Zero device timestamps leave the duration unresolved.
