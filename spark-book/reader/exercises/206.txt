Question
Which immutable image will actually run on this architecture?

Before you start

Check for success

Run in your lab

: "${LAB_RUN:?Run source reader/new_run.sh first}"

Interpret the result
A catalog listing or correct checksum is not GPU qualification.

If the check fails

Finish
