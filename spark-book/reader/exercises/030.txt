Exercise 30  Observe memory pressure during a request

Question
Which memory signals change while the oversized model answers?

Before you start

Interpret the result
A sampled peak is a lower bound on what the sampler observed. A completed request does not prove absence of paging.

If the check fails
Check dataset/tokenizer identity and memory at the failing phase before changing precision.

Finish
