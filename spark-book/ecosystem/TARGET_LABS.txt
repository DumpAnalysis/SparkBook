79  Quantization calibration and quality diagnosis

Quantization changes the numerical representation of model values. It can reduce weight traffic and storage, but savings depend on metadata, unquantized layers and executable kernels. We connect the earlier GGUF and QLoRA material to explicit ONNX quantization and TensorRT. Quantization is not a substitute for a complete memory budget or a held-out quality evaluation.

Exercise 164 Compute scales and inspect channel error

For affine integer quantization, round(x / scale) + zero_point is clipped to the representable integer range; dequantization computes scale times (q − zero_point). The scale is positive. A zero point allows an asymmetric range; the control uses signed INT8 with zero point zero and a magnitude-derived scale. ONNX’s rounding and saturation rules are part of the numerical contract. Per-channel scales must use the correct tensor axis. [137, 138]

python - <<'SCALE'

import numpy as np

w = np.load('ecosystem/controls/fixture/fixture.npz')['w']

scale = np.max(np.abs(w), axis=0) / 127

q = np.clip(np.rint(w / scale), -128, 127).astype('int8')

print('scales:', scale)

print('weight bytes:', w.nbytes, 'integer bytes:', q.nbytes)

print('scale bytes:', scale.nbytes)

SCALE

Our W has shape 8 by 4, so axis one identifies output channels. The last channel is intentionally much smaller. One tensor-wide scale wastes resolution on it; four channel scales preserve it more closely. The payload changes from 128 float32 bytes to 32 INT8 bytes plus 16 scale bytes in this example, before bias, zero points, alignment and graph metadata. That is not a fourfold reduction in the complete artifact.

Exercise 165 Expose calibration shift with an outlier


The activation scale is fitted only on ninety-six calibration rows. Thirty-two separate test rows evaluate the decision. A second test injects one activation of magnitude twelve while keeping the calibrated scale fixed. The largest output error grows from about 0.0076 to 2.84. This is an intentional distribution-shift control, not a benchmark of a published model. The transcript demonstrates why average error alone can conceal a damaging tail case.

Repeat with a deliberately wider calibration range and compare the tradeoff: fewer clipped outliers can mean coarser resolution for ordinary values. Do not tune a clipping percentile on the final test set. Split train, calibration, validation and final test by source or task where leakage is possible; exact duplicate detection is only one check. Record activation ranges, clipping counts and errors by token position, sequence length, language and rare input category for real models.
